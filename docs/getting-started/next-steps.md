# What Is Next

After a [first experiment](first-experiment.md), the following resources lead further, depending on the goal:

- To learn what an experiment can configure, read the [experiment file reference](../reference/experiment/index.md).
  The [output reference](../reference/output/index.md) describes the results.
- To follow a tutorial, see the [opendc-demos](https://github.com/atlarge-research/opendc-demos) repository, which has
  example experiments and traces.
- To drive OpenDC from code, see the [Python SDK](../python-sdk/index.md) or the [Kotlin SDK](../kotlin-sdk/index.md).
- To use OpenDC in a browser or to host it for a group, see [OpenDC as a Service](../web/index.md).
- To see what others have done with OpenDC, read about
  [existing work that uses OpenDC](https://opendc.org/research/publications).
- To ask questions and meet other users, join the [OpenDC community](https://opendc.org/community/support).
- To contribute to OpenDC, start with the [development setup](../development/index.md) and the
  [contributing guide](../development/contributing.md).
